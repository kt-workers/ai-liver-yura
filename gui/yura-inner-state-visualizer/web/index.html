HOW TO READ

光が映すもの

ゆらの内面状態を、色・動き・粒子の形に置き換えて表示しています。

色

基調色は快・不快を連続的に表し、気分が色合いをわずかに補います。粒子は均等な2群に分かれ、同時にある強い反応感情の色を表します。

形

平常時は静かな球形を保ちます。喜びは滑らかな膨らみ、愉快は弾む波、怒りは鋭い凹凸、悲しみは沈む扁平化、恐れは細かな震え、驚きは外向きの脈動、不快は不均一な歪みとして重なります。

接続

粒子の収束と画面外への拡散は、ゆらとの接続状態を表す演出です。退屈や感情による散逸ではありません。

触れる

クリックは単発波紋、ダブルクリックは二重波紋、長押しは触れている間に集まる光として現れます。ドラッグ中は軌跡だけが後端から短く消え、離した位置から波紋が広がります。それぞれ異なる刺激としてゆらへ届きます。Enter／Spaceはクリックと同じです。画面が感情値を直接変更することはなく、ゆら自身の状態と状況に応じて反応が決まります。
