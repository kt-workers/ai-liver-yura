# 内部指示器（司令塔LLM）クラウド検証モジュール設計 v1.1.1

## 1. 変更目的

v1.1.0の内部状態GUIでは、各数値項目に以下を同時表示していた。

- 操作用スライダー
- 数値入力
- スライダーと同じ値を示す横方向メーター
- 強度ラベル

スライダー自体が値の大小を視覚的に示しているため、横方向メーターは同じ情報の二重表示になっていた。v1.1.1では、画面密度を下げて状態項目を比較しやすくするため、各項目の横方向メーターを表示しない。

## 2. 表示仕様

各内部状態項目には次を表示する。

- 0〜1のスライダー
- 0〜1の数値入力
- 「とても低い／低い／中程度／高い／とても高い」の強度ラベル
- 項目キー
- 日本語表示名（既知の項目のみ）

スライダーと数値入力は引き続き双方向に同期する。横方向メーターのDOMと更新処理は既存画面との互換性のため保持してよいが、表示上は非表示とする。

## 3. 維持する可視化

内部状態グループ上部の円形サマリーは残す。

円形サマリーは各項目のスライダーと同じ値を重複表示する目的ではなく、次を一覧で比較する目的を持つ。

- グループ内の平均値
- グループ内で最も高い項目と値

対象グループ:

- 感情
- 欲求・ドライブ
- 関係性
- 動機
- 善悪・価値判断

## 4. StructuredInputMeaningの確信度

`confidence`についても、操作用スライダーと値表示があれば入力・確認できるため、追加の横方向メーターは表示しない。

## 5. API・データ契約

以下は変更しない。

- GUIとJSONの双方向同期
- `InternalDirectiveRequest`
- `POST /api/internal-directive`
- PromptBuilder、Planner、Parser
- 内部状態の0〜1正規化
- JSON入力モード

本変更は表示密度だけを調整し、司令塔LLMへ渡すJSONには影響しない。

## 6. テスト方針

ブラウザへ返すHTMLについて次を確認する。

- コンパクト表示用スタイルが適用される
- `.meter-track`が非表示になる
- 内部状態の説明がスライダーと数値入力の連動を示す
- GUI入力、JSON入力、状態サマリー、Activity入力は維持される

既存のJavaScript構文検査とAPI・認証・責務分離テストも継続する。
