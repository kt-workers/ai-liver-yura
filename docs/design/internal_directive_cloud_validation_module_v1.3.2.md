# 内部指示器クラウド検証モジュール v1.3.2

## 目的

内部指示器ラボを開いた直後の画面密度を下げ、プリセット選択、内部状態サマリー、実行操作を確認しやすくする。

## 初期表示

次の5入力領域は、画面を開いた時点で折りたたむ。

- StructuredInputMeaning
- 内部状態
- 利用可能Activity
- 進行中Activity
- Character Profile / 存在境界

各セクションのヘッダーと「展開する」ボタンは表示する。GUI入力／JSON入力の表示モード切替もヘッダーに残す。

## 内部状態サマリー

内部状態の円形サマリーは折りたたみ対象へ含めない。

感情、欲求・ドライブ、関係性、動機、善悪・価値判断の概要は、内部状態の詳細入力が閉じていても常時表示する。

## 開閉時のデータ保持

折りたたみは表示状態だけを変更する。次の値や状態は変更しない。

- GUI入力値
- JSON入力値
- GUI／JSONの表示モード
- 選択中プリセット
- LLM実行結果
- Export対象データ

プリセット適用時にも現在の折りたたみ状態を維持する。

## アクセシビリティ

初期状態では各ボタンを次の状態にする。

- `aria-expanded="false"`
- ボタン表示: `展開する`
- `aria-label`: 各セクション名を含む展開操作

展開後は既存の開閉処理により、`aria-expanded="true"`と「折りたたむ」表示へ切り替える。

## 変更範囲

本変更は検証ツールの完成HTMLにだけ適用する。Core、InternalDirective契約、API、プリセット値、Render起動コマンドは変更しない。
